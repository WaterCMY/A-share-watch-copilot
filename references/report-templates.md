# 报告模板

所有报告**涨红跌绿**、中文输出、人在回路（只做信息展示不下单）。以下为各报告的结构骨架，可直接复制改写。

---

## 一、盘前摘要（08:50）

```
# 盘前摘要 · {日期}
## 隔夜要闻
- 美股/港股/大宗：…
- 今日重大事件：…

## 持仓速览
| 代码 | 成本 | 现价 | 盈亏 | 距支撑 | 距压力 |
| … |

## 今日关注
- 支撑预警：{触及或逼近的标的}
- 压力提示：{短期不卖标的仅提示}
- 态度：持有 / 观察 / 可操作
```

```
# 竞价速览 · {时间}
```


## 六、持仓信息展示（盘中/临时）

```
# 持仓信息展示 · {时间}
## 大盘定态度
{环境 → 信息整理倾向}

- 最该关注：{A级}

```

---

### 写作纪律

- **不下单**：结尾必注明"本环境无法直接下单，减仓请在交易软件执行"。
- **遵守意图**：凡 `positions.json` 里 `user_intent=短期不卖/长持` 的标的，报告中不得催卖；压力位仅提示。
- **数据时效**：注明行情时间点（盘中/收盘），勿用滞后数据当实时。
- **风险平级**：盈利标的提示压力位、亏损标的提示支撑位，不报喜不报忧。
