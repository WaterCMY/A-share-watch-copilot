# 报告模板

所有报告**涨红跌绿**、中文输出、人在回路（只建议不下单）。以下为各报告的结构骨架，可直接复制改写。

---

## 一、盘前摘要（08:50）

```
# 盘前摘要 · {日期}
## 隔夜要闻
- 美股/港股/大宗：…
- 今日重大事件：…

## 持仓速览
| 代码 | 成本 | 现价 | 盈亏 | 距止损 | 距止盈 |
| … |

## 今日关注
- 止损预警：{触及或逼近的标的}
- 止盈提示：{短期不卖标的仅提示}
- 态度：持有 / 观察 / 可操作
```

## 二、竞价速览（09:27）

```
# 竞价速览 · {时间}
- 大盘：上证/深成/创业/科创50 高开低开
- 持仓异动（±2%）：{代码} {高/低开} {解读}
- 自选开盘强弱：…
```

# 午间总结 · {日期}

{上证/深成/创业/科创50 涨跌 + 形态描述}

## 持仓上午
- 整体盈亏：+¥{x} (+{y}%)
- 异动：{标的}

## 下午关注
- 风险点：…
- 可操作：{仅触发时列}
```

# 盘后总结 · {日期}

- 领涨/领跌板块

## 资金面

- 北向：ETF 无法纳入，注明

## 明日关注
- …
```

## 五、交易计划 / 次日策略

```
# 交易计划 · {次日日期}
## 环境判断
{大盘画像：情绪/趋势/估值/风格}

## 已锁定规则
{各标的 user_intent / 止损止盈 / 补仓计划}

## 核心态度
{持有为主触发才动 / 不追高 / 特殊日效应}

## 分级行动清单
🔴 主动可操作（价格到就办）
🟠 风控监控（跌破才动）
🟢 持有不动

## 关键价位速查表
| 标的 | 支撑/补仓 | 止损 | 止盈/减仓 |

## 自动化任务提醒
{明日会跑的任务列表}
```

## 六、持仓建议（盘中/临时）

```
# 持仓交易建议 · {时间}
## 大盘定态度
{环境 → 策略倾向}

## 分级处理
- 最该办：{A级}
- 本周内：{B级}
- 已触止盈但持有：{C级，仅提示}
- 持有不动：{核心仓}

## 一句话总结
{当天最重要的一件事}
```

---

### 写作纪律

- **不下单**：结尾必注明"本环境无法直接下单，减仓请在交易软件执行"。
- **遵守意图**：凡 `positions.json` 里 `user_intent=短期不卖/长持` 的标的，报告中不得催卖；止盈仅提示。
- **数据时效**：注明行情时间点（盘中/收盘），勿用滞后数据当实时。
- **风险平级**：盈利标的提止盈、亏损标的提止损，不报喜不报忧。
